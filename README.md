📦 Описание
Этот бот помогает клиентам получать кэшбэк за отзывы о товарах, а также решать проблемы с заказами на
маркетплейсе Wildberries. Бот интегрирован с WB API для получения информации о заказах, товарах и отзывах.

📋 Функционал
✅ Получение кешбэка за оставленный отзыв
✅ Создание заявки на решение проблемы с товаром
✅ Получение информации о заказе и товаре по номеру заказа
✅ Работа с отзывами через WB API
✅ Интерфейс с кнопками для удобства взаимодействия

🧰 Технологии
Python 3.11+
Aiogram 2.25.1
requests


🛠️ Установка и настройка
1. Создать виртуальное окружение
    
    python -m venv venv

2. Активировать окружение

Windows:
    venv\Scripts\activate

Linux/macOS:
    source venv/bin/activate

3. Установить зависимости

Создать файл requirements.txt и добавить в него:

aiogram==2.25.1
requests

Установить:
pip install -r requirements.txt

4. Создать конфигурационный файл config.py

Файл config.py должен содержать:

TG_BOT_API_TOKEN = 'ваш_токен_бота_от_BotFather'
WB_API_KEY = 'ваш_API_ключ_от_Wildberries'
ADMIN_ID = ваш_telegram_id  # можно узнать через @userinfobot

5. Запуск бота

При успешном запуске увидите:

INFO:aiogram:Бот запущен...

🔗 Интеграция с Wildberries
Бот подключается к следующим методам WB API:

Метод	                                Описание
/orders	                            Получение заказов
/orders/status	                    Получение статусов
/content/v2/get/cards/list	        Получение карточек товаров
/content/v2/object/all	            Получение категорий
/api/v2/list/goods/filter	        Получение цен
/api/v1/feedbacks	                Получение отзывов

📡 Тестирование
Если хотите локально проверить работу WB API (например, проверить наличие заказов), можно создать отдельный скрипт:

import requests
from config import WB_API_KEY

response = requests.get(
    "https://marketplace-api.wildberries.ru/api/v3/orders",
    headers={"Authorization": WB_API_KEY},
    params={"limit": 10, "next": 0}
)
print(response.json())



✅ Пример взаимодействия с ботом
1. Пользователь запускает /start
2. Выбирает: "Получить кешбэк" или "Разобраться с ситуацией"
3. Вводит номер заказа
4. Бот проверяет заказ, статус, наличие отзыва
5. Если всё в порядке — оформляется заявка на кешбэк
6. Админ получает заявку в чат и принимает решение
7. Пользователь получает уведомление о статусе заявки
